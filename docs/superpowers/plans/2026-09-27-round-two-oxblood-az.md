# Round Two: Oxblood Skin, City Imagery, EN/AZ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Re-skin the rebuilt 20-page site in the oxblood editorial world, add London/Baku photography, and publish a full Azerbaijani mirror at `/az/` with an EN/AZ toggle.

**Spec:** `docs/superpowers/specs/2026-09-27-enamplify-redesign-design.md` §12 (read it first). Product truth: `PRODUCT.md`. Current system: `DESIGN.md` (to be replaced at the end).

**Architecture:** Copy moves out of page modules into locale dictionaries (`content/copy/{en,az}.json`); locale-specific content lives in `content/az/…` overlays and `content/articles/az/*.md`. `src/i18n.mjs` defines locales and URL helpers. `routeTable(ctx)` runs once per locale; every route knows its counterpart. Rendering, SEO and the client script read the active locale. Photography is processed offline into self-hosted responsive WebP and rendered through one `photo()` component.

**House rules (tests enforce):** no U+2014 em dash in output, no `style="` attributes (CSP), no kicker/eyebrow classes, no `text-transform: uppercase`, sentence case, no trackers/storage in `site.js`, one H1 per page, every internal link resolves. Budgets: CSS ≤ 36 KB, JS ≤ 12 KB. Commit trailer: blank line then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

- [ ] `src/i18n.mjs` exports `locales = {en: {code: 'en', lang: 'en-GB', hreflang: 'en-GB', prefix: '', ogLocale: 'en_GB', label: 'EN', name: 'English'}, az: {code: 'az', lang: 'az', hreflang: 'az', prefix: '/az', ogLocale: 'az_AZ', label: 'AZ', name: 'Azərbaycanca'}}`, `localePath(locale, path)` (prefix + path; `/` → `/az/` for az), and `otherLocale(code)`.
- [ ] **Copy extraction.** Every user-visible string currently in `src/pages/*.mjs`, `src/pages/shared.mjs`, `src/components.mjs` (skip link, Menu, Book a call, Home crumb, footer headings/links text, close band defaults, card meta words like "min read", "Field guide"), `src/routes.mjs` (titles, descriptions, crumb labels), exhibit labels/units ("Before", "After", "hours", "Month 1", …) moves into `content/copy/en.json`, grouped by page (`common`, `home`, `approach`, `work`, `about`, `insights`, `article`, `guide`, `contact`, `legal`, `notFound`, `routes`). Page modules receive `ctx.copy` and read from it. No copy strings remain hard-coded in `src/` (a test greps `src/pages/*.mjs` for a few known English phrases and must find none).
- [ ] `loadContent(localeCode)` loads base content and, for `az`, deep-merges overlays from `content/az/{site,work,faqs,articles,resources}.json` when present and reads essays from `content/articles/az/<slug>.md` (falls back to English only if a file is missing, and records the fallback in `ctx.missing` so a test can assert none are missing once R2 lands). It also loads `content/copy/<locale>.json` into `ctx.copy`. Absent `az` files must not break the build during R1.
- [ ] **Routes per locale.** `routeTable(ctx)` builds the same 20 routes with URLs passed through `localePath`. Each route gets `locale`, `key` (a stable id such as `home`, `article:<slug>`, `legal:privacy`) and `alternates` (`{en: url, az: url}`). The build renders EN and AZ route sets (AZ with English fallback copy until R2) → 40 pages. The 404 stays one bilingual page at `/404/` (+ `404.html`); no `/az/404/`.
- [ ] **Internal links** generated by components and pages go through `localePath(ctx.locale, …)` so AZ pages link to AZ pages. Links to `/downloads/*.pdf`, `/feed.xml`, `/fonts`, `/images`, `/assets` are not prefixed; AZ pages link `/az/feed.xml`.
- [ ] **Header toggle.** In the header (desktop, after the nav, before the CTA) and at the end of the mobile menu: `<nav class="lang" aria-label="{copy.common.language}">` with two items; the current one is `<span aria-current="true" lang="…">EN</span>`, the other `<a href="{alternate}" hreflang="…" lang="…">AZ</a>`, each with a visually hidden full language name. On `/404/` the toggle links to `/` and `/az/`.
- [ ] **SEO.** `renderDocument` uses the route's locale: `<html lang>`, `og:locale` + `og:locale:alternate`, `<link rel="alternate" hreflang="en-GB|az|x-default">` (x-default → EN URL) on every page except 404, canonical to self, JSON-LD `inLanguage` per page (WebSite gets `["en-GB","az"]`), breadcrumbs localised. Sitemap lists all indexable EN and AZ URLs with `xhtml:link` alternates (add the `xmlns:xhtml` namespace). Feeds: `/feed.xml` (EN) and `/az/feed.xml` (AZ); pages link the feed of their locale. `llms.txt` gets an "Azərbaycanca" section listing AZ pages.
- [ ] **Client strings.** `renderDocument` emits `<script type="application/json" id="ui-strings">{…}</script>` with the strings `site.js` shows (Menu/Close, form error messages, composer result text, Copied, Copy the message, Open my email app, Sending…, sent/failed messages, print placeholder, clear-notes confirm). `site.js` reads them (`JSON.parse(document.getElementById('ui-strings').textContent)`) with English defaults if missing. JSON must escape `<` like the JSON-LD. Budget ≤ 12 KB.
- [ ] **Tests.** New `tests/i18n.test.mjs`: `localePath` cases; every route has both alternates; AZ route URLs are EN URLs with `/az` prefix; no page-module English phrase leakage. Update `tests/site.test.mjs`: page count 40, hreflang alternates on every non-404 page and they point at existing files, `<html lang="az">` on `/az/` pages, sitemap has `xhtml:link`, toggle present on every page, AZ pages' internal links stay under `/az/` (except assets/downloads/feeds), ui-strings JSON parses. Update unit tests that asserted hard-coded strings to use the copy.
- [ ] `npm run check` green; English visible text identical to the golden snapshot apart from the toggle. Commit "feat(i18n): locale-aware copy, routes, SEO and toggle".
