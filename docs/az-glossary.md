# Azerbaijani glossary

Fixed renderings for the Enamplify Azerbaijani pages (`/az/…`). Every AZ string in `content/copy/az.json`, `content/az/*.json` and `content/articles/az/*.md` follows this list. Change a term here first, then everywhere.

## Register and typography

- Formal "siz" throughout (Siz is not capitalised mid-sentence). Calm, specific, no hype; the same claims as English and no more.
- Latin script with the full alphabet: ə Ə, ı I, i İ, ş Ş, ç Ç, ğ, ö Ö, ü Ü. Capital dotted İ at the start of words such as "İdarəetmə", "İşlərimiz", "İngilis".
- Sentence case in headings and titles.
- Quotation marks: “ ” only (not « », not straight quotes).
- No em dash (U+2014) and no dash as punctuation. Use a comma, colon or a new sentence. The en dash appears only in ranges: "2–3 həftə", "8–12 həftə".
- Suffixes on abbreviations and brand names take a hyphen: Sİ-ni, Sİ-nin, Sİ-dən, Sİ-yə, Sİ-lə; Enamplify-ın, Enamplify-da (read "enemplay").
- Dates: "26 sentyabr 2026" (month in lower case).
- Numbers stay as numerals: "30 dəqiqə", "10+ il". Money keeps the English form "$10,000" so the figure is identical on both sites.

## Names (never translated)

Enamplify, RAG Medium, grademy, pripitch, RAG-X, Google, Resend, Cloudflare Turnstile, LinkedIn, WCAG 2.2 AA, Amir Gulubayli.
Cities: London → London; Baku → Bakı. UK → Böyük Britaniya; EU → Avropa İttifaqı (short: Aİ).

## Fixed lines

- Hero: "Komandanızın qurduğu Sİ." / "Satın aldığınız Sİ deyil."
- Positioning in running text: "Satın aldığınız deyil, komandanızın qurduğu Sİ."
- "Start small. Prove it. Then scale." → "Kiçikdən başlayın. Sübut edin. Sonra genişləndirin."
- "When the timing is right, start with a conversation." → "Vaxtı çatanda, söhbətlə başlayın."
